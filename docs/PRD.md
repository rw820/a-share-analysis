# A股个股分析工具 — 功能增强 PRD

> 版本: v2.0 | 日期: 2026-05-02 | 状态: 待评审

---

## 1. 背景与目标

### 1.1 现状

当前 v1.0 的分析完全依赖技术面（量价指标），缺少对股票基本面的考量。分析维度单一，无法区分"技术面好看但基本面差"和"基本面扎实且技术面共振"两种情况。

### 1.2 目标

引入基本面、资金面、消息面、风险度量和行业对比 5 大类分析，将信号体系从 6 个扩展到 12 个，形成更全面的分析画像。

### 1.3 术语约定

- **红涨绿跌**：中国股市惯例，红色=上涨=看多，绿色=下跌=看空（本工具信号颜色遵循此约定）
- **PE 口径**：优先使用 **PE-TTM**（滚动市盈率，近 4 个季度），如数据源只提供静态 PE 则用静态 PE 并标注口径
- **主力资金**：超大单（单笔 ≥100 万元）+ 大单（单笔 20-100 万元）的合计净流入

## 2. 功能需求

### F1: 估值分析

**优先级**: P0  
**数据源**: `akshare` — `stock_a_lg_indicator()`  
**备用数据源**: `akshare` — `stock_individual_info_sw()`（申万个股指标）  
**缓存**: TTL=4 小时  
**依赖**: 无

| 需求编号 | 描述 |
|----------|------|
| F1.1 | 获取并展示 PE-TTM（优先）/ 静态 PE（兜底）、PB、PS、总市值、流通市值 |
| F1.2 | 获取 PE/PB 历史数据，计算当前值在近 3 年、近 5 年的分位数。若数据不足 3 年则只展示可用年份分位并标注"数据不足N年" |
| F1.3 | 根据分位数生成估值信号：分位 ≤25%=低估(看多, red)，25%<分位<75%=合理(中性, amber)，分位 ≥75%=高估(看空, green)。分位恰好等于 25% 归入低估，恰好等于 75% 归入高估 |
| F1.4 | 展示 PE 历史走势图（含 25%/75% 分位标注线及当前值高亮） |
| F1.5 | 亏损企业（PE 为负）：不参与分位比较，PE 展示为"亏损"，信号标记为 special 类型，不纳入综合评分；PB >0 仍正常展示 PB 及 PB 分位 |
| F1.6 | 次新股（上市 < 1 年）：分位展示"上市时间过短，数据不足"，仅展示当前 PE/PB 绝对值，信号不纳入综合评分 |

### F2: 财务健康与成长性

**优先级**: P0  
**数据源**: `akshare` — `stock_financial_analysis_indicator()`  
**备用数据源**: `akshare` — `stock_financial_abstract_ths()`（同花顺口径）  
**缓存**: TTL=24 小时  
**依赖**: 无

| 需求编号 | 描述 |
|----------|------|
| F2.1 | 获取最近 4-8 期单季度财报核心指标：营业总收入、归母净利润、ROE(加权)、毛利率、净利率、资产负债率、经营活动现金流净额 |
| F2.2 | 计算各指标同比增长率（YoY，与去年同期单季度比较）。若去年同期数据不存在则标注"N/A" |
| F2.3 | 趋势判断：近 3 期净利润连续增长且最新 YoY>0=增长(看多)；近 3 期连续下滑且最新 YoY<0=下滑(看空)；其他=波动(中性) |
| F2.4 | 特殊情况：最新一期净利润 YoY < -50% = "业绩大幅下滑"，信号强制看空；YoY > 100% = 亮黄色标记（可能为非经常性损益） |
| F2.5 | 展示指标趋势图：柱状图显示各季度营收/净利润绝对值，折线显示 YoY 增长率；另展示 ROE、毛利率、净利率三线趋势图 |
| F2.6 | 字段兼容：akshare 返回字段可能因版本变化，实现层做字段名映射表（如 `净利润` / `归母净利润` / `parent_net_profit` 均可识别），新增字段名只需更新映射表 |

### F3: 资金流向分析

**优先级**: P1  
**数据源**: `akshare` — `stock_individual_fund_flow()`（个股资金流向日频）  
**缓存**: TTL=1 小时  
**依赖**: 无

| 需求编号 | 描述 |
|----------|------|
| F3.1 | 获取个股日频资金流向明细：主力净流入=超大单净流入+大单净流入，散户净流入=中单净流入+小单净流入 |
| F3.2 | 汇总近 5 日、20 日主力累计净流入（连续逐日累加，非简单平均） |
| F3.3 | 信号判断：主力 5 日累计净流入>0 且 20 日累计净流入>0=主力持续流入(看多)；两者皆负=主力持续流出(看空)；一正一负=分歧(中性) |
| F3.4 | 展示资金流向柱状图：每日分 4 色堆叠（超大单/大单/中单/小单），红=净流入，绿=净流出 |
| F3.5 | 资金流向金额标注单位：亿（如 +1.23 亿），当金额 < 1 亿时切换为万 |

### F4: 风险指标

**优先级**: P1  
**数据源**: 
- K线数据：基于已有 baostock K 线（即现有 `get_kline_data` 的结果）
- **沪深 300 指数数据**：`akshare` — `stock_zh_index_daily()` 或 `baostock` — `query_history_k_data_plus(sz.399300)`  
**缓存**: 风险指标跟随 K 线数据缓存，不独立缓存  
**依赖**: `data/market_data.py` 需新增指数 K 线获取函数

| 需求编号 | 描述 |
|----------|------|
| F4.1 | 计算近 60 日、120 日、250 日最大回撤。算法：从区间内任意峰值到后续最低谷的最大跌幅百分比。若区间内无回撤则返回 0 |
| F4.2 | 计算年化波动率：近 20 日（或可选周期）日收益率标准差 × √252 |
| F4.3 | 计算相对沪深 300 的 Beta：对近 60 日（至少需要 40 个有效交易日）个股日收益率和沪深 300 日收益率做 OLS 线性回归，Beta = 回归斜率。若指数数据获取失败则 Beta 标记为"N/A"不参与风险等级计算 |
| F4.4 | 计算夏普比率：`(年化收益率 − 无风险利率) / 年化波动率`。无风险利率从 `config.py` 读取（默认 3%/年）。年化收益率 = 近 250 日日均收益率 × 252 |
| F4.5 | 输出风险等级（取各指标对应的最高等级）：

| 等级 | 最大回撤(60日) | 年化波动率 | Beta |
|------|:------------:|:--------:|:----:|
| 低风险 | < 10% | < 25%  | < 1.0 |
| 中风险 | 10% ~ 25% | 25% ~ 45% | 1.0 ~ 1.5 |
| 高风险 | > 25% | > 45% | > 1.5 |

> 边界值归属：恰好等于阈值时归入较低风险等级（如回撤恰好 10%=中风险）

| F4.6 | **风险等级不作为看多/看空信号**。风险等级信号卡片展示为 special 类型（蓝色边框），用于提示而非方向判断，不参与综合评分。高风险≠看空，只是提醒波动较大 |

### F5: 融资融券

**优先级**: P2  
**数据源**: 
- 上交所股票：`akshare` — `stock_margin_detail_sse()`
- 深交所股票：`akshare` — `stock_margin_detail_szse()`  
**缓存**: TTL=2 小时  
**依赖**: 需根据代码前缀自动选择 SSE 或 SZSE 接口

| 需求编号 | 描述 |
|----------|------|
| F5.1 | 获取融资余额、融资买入额、融券余量。根据股票代码判断交易所，自动选择对应接口 |
| F5.2 | 计算融资余额占流通市值比例（> 5% 标记为"高杠杆"，有炒作风险） |
| F5.3 | 融资余额趋势：近 10 日数据，用线性回归拟合斜率。斜率 > 0 且近 5 日连续增加=持续增加(偏多)；斜率 < 0 且近 5 日连续减少=持续减少(偏空)；其他=震荡(中性) |
| F5.4 | 非两融标的（接口返回空或股票不在两融列表）：信号显示"非两融标的"，不参与综合评分 |

### F6: 公告与事件 + 分红

**优先级**: P2  
**数据源**: 
- 公告：`akshare` — `stock_notice_report()`
- 分红：`akshare` — `stock_dividents_cninfo()`  
**缓存**: TTL=6 小时  
**依赖**: 无

| 需求编号 | 描述 |
|----------|------|
| F6.1 | 获取近 30 天 / 90 天公告标题列表 |
| F6.2 | 关键词识别公告类型：业绩预告 → `earnings_forecast`，业绩快报 → `earnings_report`，分红预案 → `dividend`，增发 → `refinance`，股东增减持 → `shareholder_trade`，重大合同/诉讼 → `major_event`，其他 → `other` |
| F6.3 | 展示业绩预告/快报摘要：预计净利润（区间或单值）、同比变化方向（预增/预减/扭亏/续亏/首亏） |
| F6.4 | 获取近 3 年分红记录：每股股利、股息率、除权除息日。计算年均股息率，连续分红年数。年均股息率 > 2% 且连续分红 > 3 年标记为"高股息现金奶牛" |
| F6.5 | 事件信号生成：近期有业绩预告（预增/扭亏）→ 偏多；有业绩预告（预减/首亏/续亏）→ 偏空；有股东大额减持 → 偏空；有重大合同/中标 → 偏多。综合多项事件取最突出方向 |

### F7: 行业对比

**优先级**: P2  
**数据源**: 
- 行业分类：`akshare` — `stock_individual_info_sw()`（申万行业分类）
- 行业估值：`akshare` — `stock_board_industry_pe()` 或计算业内个股 PE 中位数  
**缓存**: TTL=4 小时  
**依赖**: 依赖 F1 的个股 PE 数据

| 需求编号 | 描述 |
|----------|------|
| F7.1 | 获取个股所属申万一级/二级行业 |
| F7.2 | 获取行业 PE（TTM）中位数，计算个股 PE / 行业 PE 中位数的比值 |
| F7.3 | 比值 < 0.8 = "显著低于行业均值"，0.8~1.2 = "与行业持平"，> 1.2 = "显著高于行业均值" |
| F7.4 | 亏损企业或行业 PE 数据不可用时：仅展示行业名称，估值对比显示"N/A" |

### 3.3 综合评分机制

**从简单计数升级为加权评分**，总分范围 [-1, 1]：

| 一级分类 | 权重 | 包含信号 | 二级权重分配 |
|----------|:----:|----------|:----------:|
| 技术面 | 0.35 | 趋势、RSI、MACD、量价（4 个） | 各 0.25 |
| 预测 | 0.20 | ML 预测、ARIMA（2 个） | 各 0.50 |
| 基本面 | 0.25 | 估值水平、盈利增长（2 个） | 各 0.50 |
| 资金面+消息面 | 0.20 | 资金流向、融资融券、事件提醒（3 个） | 各 0.33 |

- 每个信号：看多 = +1，看空 = -1，中性 = 0
- 信号 unavailable（数据获取失败）：不纳入计算，其权重按比例分配给同组其他信号
- 评分 > +0.15 → "偏多"，< −0.15 → "偏空"，[−0.15, 0.15] → "多空交织，建议观望"
- 亏损股（PE<0）：估值信号不参与评分，基本面权重全部转移到盈利增长信号上

### 3.4 指标冲突时的仲裁规则

当估值信号与技术面信号方向相反时，综合判定的文字中补充说明：
- 估值看多 + 技术面看空 → "基本面低估但技术面偏弱，中长线可关注但短线等待企稳信号"
- 估值看空 + 技术面看多 → "技术面强势但估值偏高，注意追高风险"

## 4. 技术约束

| 约束 | 说明 |
|------|------|
| 数据源 | 优先 akshare，baostock 兜底。不引入付费 API |
| 最低版本 | akshare ≥ 1.12.0（接口稳定性考虑） |
| 缓存策略 | 基本面 TTL≥4h，财报 TTL=24h，行情相关 TTL≤1h |
| 容错处理 | 所有新数据源获取失败时降级为不显示该模块，不阻塞其他模块 |
| 超时限制 | 每个 akshare/http 调用设置 15s 超时，超时视为获取失败 |
| 加载速度 | 新模块默认折叠（expander），避免首屏加载过慢 |
| 兼容性 | 保持现有 K 线图和分析逻辑不变 |
| 字段映射 | 所有 akshare 返回字段通过映射表转换，避免 akshare 版本升级导致字段名变化而崩溃 |
