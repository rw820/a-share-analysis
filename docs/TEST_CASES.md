## 测试策略

| 层级 | 范围 | 工具 |
|------|------|------|
| 单元测试 | 每个分析模块的计算逻辑独立测试（Mock 外部数据源） | pytest |
| 集成测试 | 数据获取 → 计算 → 信号生成全链路 | pytest |
| UI 测试 | Streamlit 页面渲染与交互 | 手动 / Playwright |
| 异常测试 | 数据源不可用、空数据、边界值、接口格式变更 | pytest |

## TC1: 估值分析 (F1)

### TC1.1 正常获取估值数据（盈利企业）

| 项 | 内容 |
|----|------|
| **前置条件** | akshare 可用，传入 sh.600519（贵州茅台，PE 为正） |
| **步骤** | 调用 `get_valuation_data(bs_code)` |
| **预期** | 返回 dict，包含 `pe`, `pb`, `ps`, `total_mv`, `float_mv`，均为数值 |
| **断言** | `result["pe"]` 为 float 且不等于 None；`result["pb"] > 0`；`result["total_mv"] > 0` |

### TC1.2 估值分位数计算

| 项 | 内容 |
|----|------|
| **前置条件** | 有 ≥ 3 年 PE 历史数据 |
| **步骤** | 传入 PE 历史序列 `pe_history`，当前 PE = 15，序列中 80% 的值 > 15，调用 `calc_percentile(pe_history, current_pe)` |
| **预期** | 返回当前 PE 在 3 年/5 年的分位数（0-100 之间的 float） |
| **断言** | `0 <= pct_3y <= 100`，`0 <= pct_5y <= 100`；若 PE=15 且在序列的 20% 低位，则分位数 ≈ 20 |

### TC1.3 估值信号生成 — 低估（分位 < 25%）

| 项 | 内容 |
|----|------|
| **前置条件** | Mock PE 分位数 = 10%（< 25%） |
| **步骤** | 调用 `get_valuation_signal(pct=10)` |
| **预期** | 信号=(估值水平, "低估 10%分位", red, "当前估值处于近N年10%分位...") |

### TC1.4 估值信号生成 — 高估（分位 > 75%）

## TC2: 财务健康与成长性 (F2)

### TC2.1 正常获取财务数据

| 项 | 内容 |
|----|------|
| **前置条件** | akshare 可用，传入 sh.600519 |
| **步骤** | 调用 `get_financial_data(bs_code)` |
| **预期** | 返回最近 4-8 期季报数据：营业总收入、归母净利润、ROE、毛利率、净利率、资产负债率、经营现金流 |
| **断言** | `len(result["quarters"]) >= 4`；每期的各项指标为数值（可为负）；字段名经过映射表转换后统一 |

### TC2.2 YoY 增长率计算

| 项 | 内容 |
|----|------|
| **前置条件** | 有 Q1-2025（净利润 10 亿）和 Q1-2024（净利润 8 亿）同季度数据 |
| **步骤** | 调用 `calc_yoy_growth(current=10, previous=8)` |
| **预期** | 返回 `25.0`（即 (10-8)/8 × 100%） |
| **断言** | `result == 25.0` |

### TC2.3 YoY — 去年同期数据缺失

| 项 | 内容 |
|----|------|
| **前置条件** | 最新一期有数据，去年同期无数据（新股/上市未满 1 年） |
| **步骤** | 调用 `calc_yoy_growth(current=10, previous=None)` |
| **预期** | 返回 None，展示时显示"N/A" |
| **断言** | `result is None` |

### TC2.4 趋势判断 — 持续增长

| 项 | 内容 |
|----|------|
| **前置条件** | 近 3 期净利润分别为 [8, 10, 12]（连续增长），最新 YoY > 0 |
| **步骤** | 调用 `judge_financial_trend(financials)` |
| **预期** | trend="增长"，信号方向=看多(red) |
| **断言** | `result["trend"] == "增长"`；`result["signal"] == "bull"` |

### TC2.5 趋势判断 — 业绩大幅下滑

| 项 | 内容 |
|----|------|
| **前置条件** | 最新一期净利润 YoY = -55%（< -50% 阈值） |
| **步骤** | 调用 `judge_financial_trend(financials)` |
| **预期** | trend="大幅下滑"，信号强制看空(green)，备注"⚠ 业绩大幅下滑" |
| **断言** | `result["signal"] == "bear"`；`result["alert"] == True` |

### TC2.6 趋势判断 — YoY > 100% 异常标记

| 项 | 内容 |
|----|------|
| **前置条件** | 最新一期净利润 YoY = 150%（> 100% 阈值） |
| **步骤** | 调用 `judge_financial_trend(financials)` |
| **预期** | 信号上出现黄底标记 ⚡"可能为非经常性损益"，但仍按趋势输出方向 |

### TC2.7 字段映射表容错

| 项 | 内容 |
|----|------|
| **前置条件** | Mock akshare 返回字段名为英文 `net_profit` 而非中文 `归母净利润` |
| **步骤** | 调用 `get_financial_data()` 内部执行字段映射 |
| **预期** | 映射表成功匹配 `net_profit` → `归母净利润`，数据正常解析 |
| **断言** | `"归母净利润" in result["quarters"][0]` |

### TC2.8 数据源不可用

| 项 | 内容 |
|----|------|
| **前置条件** | akshare 抛异常 + 备用数据源也不可用 |
| **步骤** | 调用 `get_financial_data()` |
| **预期** | 返回 `{"success": False}`；不抛异常上抛 |

## TC4: 风险指标 (F4)

### TC4.1 最大回撤计算 — 有具体数据验证

| 项 | 内容 |
|----|------|
| **前置条件** | K 线收盘价序列 = `[10, 12, 8, 9, 11]` |
| **步骤** | 调用 `calc_max_drawdown(prices)` |
| **预期** | 最大回撤 = (12 − 8) / 12 = 33.33% |
| **断言** | `abs(md - 0.3333) < 0.001` |

### TC4.2 最大回撤 — 持续上涨无回撤

| 项 | 内容 |
|----|------|
| **前置条件** | K 线收盘价序列 = `[10, 11, 12, 13, 14, 15]`（严格单调递增） |
| **步骤** | 调用 `calc_max_drawdown(prices)` |
| **预期** | 最大回撤 = 0 |
| **断言** | `md == 0.0` |

### TC4.3 最大回撤 — 多次回撤取最大

| 项 | 内容 |
|----|------|
| **前置条件** | 序列 = `[10, 15, 12, 20, 8, 14]`。第一次回撤 (15-12)/15=20%，第二次回撤 (20-8)/20=60% |
| **步骤** | 调用 `calc_max_drawdown(prices)` |
| **预期** | 返回 60% |
| **断言** | `abs(md - 0.60) < 0.001` |

### TC4.4 年化波动率

| 项 | 内容 |
|----|------|
| **前置条件** | 有 ≥ 20 日 K 线收盘价 |
| **步骤** | `std(日收益率) × √252` |
| **预期** | 结果为 0-500% 之间的合理值（A 股通常在 15%-80%） |
| **断言** | `0 < vol < 5.0` |

### TC4.5 Beta 计算 — 正常场景

| 项 | 内容 |
|----|------|
| **前置条件** | 有近 60 日个股日收益率 + 沪深 300 日收益率（均 ≥ 40 个有效交易日） |
| **步骤** | 1. 从 baostock 获取沪深 300（sz.399300）近 60 日 K 线 2. 对齐个股和指数日期 3. 对日收益率做 OLS，取斜率 |
| **预期** | Beta ≈ 回归斜率（一般在 0.5-1.5 之间） |
| **断言** | `0 < beta < 3` |

### TC4.6 Beta 降级 — 指数数据获取失败

| 项 | 内容 |
|----|------|
| **前置条件** | Mock 沪深 300 数据获取抛异常 |
| **步骤** | 调用 `calc_beta(stock_returns, index_returns=None)` |
| **预期** | Beta 返回 None；风险等级计算中跳过 Beta 维度；展示时 Beta 显示"N/A"；日志记录降级 |
| **断言** | `result["beta"] is None`；`result["degraded"] == True` |

### TC4.7 夏普比率

| 项 | 内容 |
|----|------|
| **前置条件** | 年化收益率 = 12%，年化波动率 = 25%，无风险利率 = 3% |
| **步骤** | `(0.12 - 0.03) / 0.25` |
| **预期** | 夏普 = 0.36 |
| **断言** | `abs(sharpe - 0.36) < 0.01` |

### TC4.8 风险等级 — 边界值（恰好等于阈值）

| 项 | 内容 |
|----|------|
| **前置条件** | 最大回撤恰好 = 10%，波动率恰好 = 25%，Beta 恰好 = 1.0 |
| **步骤** | 调用 `calc_risk_level(md=10%, vol=25%, beta=1.0)` |
| **预期** | 归入"中风险"（边界值归入较低等级中是递增方向：低→中，但恰好等于低风险上限归入中风险）。按 PRD F4.5 表格：回撤 10% = 中风险，波动 25% = 中风险，Beta 1.0 = 中风险 → 综合=中风险 |
| **断言** | `risk_level == "中风险"` |

### TC4.9 风险等级 — 混合场景取最高

| 项 | 内容 |
|----|------|
| **前置条件** | 回撤=5%（低），波动=50%（高），Beta=0.8（低） |
| **步骤** | 调用 `calc_risk_level(md=5%, vol=50%, beta=0.8)` |
| **预期** | 综合等级="高风险"（各维度取最劣等级） |
| **断言** | `risk_level == "高风险"` |

### TC4.10 风险信号不参与方向评分

| 项 | 内容 |
|----|------|
| **前置条件** | 风险等级=高风险 |
| **步骤** | 调用综合评分计算 `calculate_score(all_signals)` |
| **预期** | 风险信号不在方向计数中（不贡献看多/看空票数），仅作为独立提示展示 |
| **断言** | `risk_signal not in score_direction_signals` |

## TC6: 公告与事件 + 分红 (F6)

### TC6.1 获取近期公告列表

| 项 | 内容 |
|----|------|
| **前置条件** | akshare 可用 |
| **步骤** | 传入 sh.600519，调用 `get_recent_notices(bs_code, days=30)` |
| **预期** | 返回列表 `[{title, date, type}, ...]`，datetime 类型已正确转换 |
| **断言** | `len(result) >= 0`；每条 `title` 和 `date` 非空 |

### TC6.2 公告类型关键词识别

| 项 | 内容 |
|----|------|
| **前置条件** | 公告列表包含多类公告 |
| **步骤** | 调用 `classify_notices(notices)` |

| 标题（示例） | 预期 type |
|-------------|-----------|
| 2024年年度业绩预告 | `earnings_forecast` |
| 2024年年度报告 | `earnings_report` |
| 2024年度利润分配预案 | `dividend` |
| 非公开发行A股股票预案 | `refinance` |
